# Kader Hosaf — Portfolio Website

A responsive portfolio landing page built with HTML, CSS and vanilla JavaScript.

## Upload to GitHub
Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder to the root of your repository. Keep the folder structure unchanged.

## Customize
- Text, links and projects: `index.html`
- Colors, typography, layout and animations: `style.css`
- Menu and scroll behavior: `script.js`
- Images: `assets/*.webp`

The project cards currently link to the contact section. Individual project pages can be added in a later version.

Images are adapted from the portfolio PDF supplied by the website owner. The Google Fonts used are Barlow Condensed and DM Sans.
